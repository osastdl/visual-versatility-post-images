# Visual Versatility — post images

Image assets for the [visual-versatility-autopost](https://github.com/osastdl/visual-versatility-autopost) scheduler. Nothing sensitive lives here — just image files, referenced by `content/calendar.json` in the autopost repo via their raw GitHub URL (`https://raw.githubusercontent.com/osastdl/visual-versatility-post-images/main/<filename>`).

This repo is public because Instagram/Facebook's API can only fetch images from a public URL — it can't read from a private repo.
